# Smart Cleaner Privacy Policy Draft

Last updated: 17 August 2026

Smart Cleaner analyzes storage on the user's device to provide cleaning suggestions. Photos, videos, and file contents are not uploaded to the developer's servers for analysis. The analysis runs on the device.

The app may request access to photos and videos so it can display cleaning suggestions. Android limits this access according to the permission selected by the user. The user can revoke access at any time in Android Settings.

On Android 8.0 and newer, the optional App Cache Manager requests Usage Access to read app storage statistics exposed by Android. The app processes the installed app label, package name, and reported cache byte total on the device. It does not read personal file contents or upload this information to the developer. Package visibility is limited to user-launchable apps; the app does not request broad `QUERY_ALL_PACKAGES` access. Usage Access can be revoked at any time in Android Settings.

Smart Cleaner never deletes files without the user's selection. On supported Android versions, deletion also uses Android's system confirmation screen.

The app uses Google Mobile Ads SDK and Google's User Messaging Platform. Depending on the user's region and consent choices, these services may process device identifiers, diagnostics, ad interaction data, and approximate location for advertising, fraud prevention, measurement, and consent management. The final published policy and Google Play Data safety form must match the live AdMob and UMP configuration.

The app does not claim to force-stop other apps, cool the CPU, or silently clear private cache belonging to other apps. For another app's cache, it opens Android's official app-details screen so the user can choose the action. Android manages system memory and protects application-private storage.

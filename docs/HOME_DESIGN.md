# Home design — Cleaner Engine 0.5

The selected modern Smart Cleaner visual identity and shield/brush launcher icon remain unchanged.

Home hierarchy:

1. Smart Cleaner hero with real storage usage and **START DEEP SMART SCAN**.
2. Clear All files access status when the storage engine is not enabled.
3. High-value cleaner cards: Junk Cleaner, Duplicate Cleaner, Large Files, Media Cleaner.
4. Full-width WhatsApp Cleaner, Deep App Cache, Downloads & APK and RAM Optimization rows.

The home screen no longer presents battery/CPU/device-status cards as cleaning tools.

All cleaner cards map to a distinct engine operation. No home card may claim device-wide cleanup while calling only `clearOwnCache()`.
